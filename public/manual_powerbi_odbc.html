Manual de conexión ODBC para Power BI

Este documento explica cómo configurar la conexión ODBC hacia Supabase/PostgreSQL y cómo abrir el archivo de Power BI preparado para Paseo San Francisco.

Importante: este manual contiene credenciales de conexión. Compártalo únicamente con personas autorizadas.

1. Requisitos

  • Windows con Power BI Desktop instalado.
  • Permisos para instalar controladores ODBC.
  • Archivo de Power BI entregado: PaseoSanFrancisco.pbix o PaseoSanFrancisco.pbit.
  • Conexión a internet para acceder a Supabase.

2. Instalar el controlador ODBC de PostgreSQL

  1. Descargue el instalador de PostgreSQL ODBC desde https://www.postgresql.org/ftp/odbc/releases/.
  2. Seleccione el instalador de 64 bits, normalmente llamado psqlodbc_x64.msi.
  3. Ejecute el instalador y complete el proceso con las opciones predeterminadas.
  4. Cierre Power BI Desktop si estaba abierto y vuelva a abrirlo después de instalar el controlador.

3. Crear el origen de datos ODBC

  1. En Windows, busque y abra ODBC Data Sources (64-bit) o Orígenes de datos ODBC (64 bits).
  2. Abra la pestaña System DSN o DSN de sistema.
  3. Haga clic en Add o Agregar.
  4. Seleccione PostgreSQL ODBC Driver(UNICODE) y haga clic en Finish.

  1. Haga clic en Test o Probar.
  2. Si la prueba es exitosa, haga clic en Save, OK o Aceptar.

4. Abrir el archivo en Power BI Desktop

  1. Abra Power BI Desktop.
  2. Abra el archivo entregado: PaseoSanFrancisco.pbix o PaseoSanFrancisco.pbit.
  3. Si Power BI solicita credenciales para el origen ODBC, seleccione Base de datos.
  4. Ingrese el usuario y contraseña indicados en la sección de datos de conexión.
  5. Deje vacío el campo Propiedades de la cadena de conexión de credenciales.
  6. Haga clic en Conectar.

5. Conectar desde cero en Power BI Desktop

Si necesita crear la conexión manualmente desde Power BI Desktop:

  1. Seleccione Inicio > Obtener datos > Más....
  2. Seleccione ODBC.
  3. En el listado de DSN, seleccione Supabase PowerBI.
  4. Seleccione el modo Importar.
  5. Cuando aparezca el navegador, seleccione únicamente las vistas que empiezan con vw_powerbi_.
  6. Haga clic en Cargar.

6. Actualizar datos

  1. Abra el archivo de Power BI.
  2. Verifique que el origen ODBC Supabase PowerBI exista en el equipo.
  3. En Power BI Desktop, haga clic en Actualizar.
  4. Espere a que finalice la carga de datos.

7. Solución de problemas

Problema Solución sugerida
No aparece el controlador PostgreSQL ODBC Instale el controlador psqlodbc_x64.msi y abra el administrador ODBC de 64 bits.
Error de certificado SSL Use ODBC con SSL Mode = require.
Falla la autenticación Revise que el usuario sea postgres.cgzylyeoepdsgxzywicv y que la contraseña esté escrita exactamente igual.
No se ven las vistas Confirme que se seleccionó la base postgres y el DSN Supabase PowerBI.
El reporte no actualiza Verifique conexión a internet, credenciales ODBC y permisos del origen de datos en Power BI.
